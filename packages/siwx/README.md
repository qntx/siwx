# @qntx/siwx

Sign-In with X ([CAIP-122](https://chainagnostic.org/CAIPs/caip-122)) for
TypeScript: SIWE, SIWS, message parsing, validation, and signature
verification. The Rust implementation lives in `crates/siwx`; both sides are
kept in lockstep against the shared golden data in `vectors/` (see
`parity.json`).

```bash
bun add @qntx/siwx
```
