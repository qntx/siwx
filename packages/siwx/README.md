# `@qntx/siwx`

[Sign-In with X](https://chainagnostic.org/CAIPs/caip-122) (CAIP-122) for TypeScript: message construction, parsing, binding checks and signature verification for EVM (`@qntx/siwx/evm`, EIP-4361) and Solana (`@qntx/siwx/svm`, SIWS). Platform-neutral and Hermes-safe; behaviorally identical to the [siwx](https://crates.io/crates/siwx) crate.

See the [documentation](https://github.com/qntx/siwx/tree/main/docs).
