# SVM

```ts
import { svm, siws, validateAddress, offchainMessage } from "@qntx/siwx/svm";

const ns = svm();
const text = siws.format(message); // SIWS text
const envelope = offchainMessage(text, addr); // v1 envelope for wallets
```

- `parse` accepts raw SIWS text or the off-chain v1 envelope (16-byte
  `\xffsolana offchain` domain + version + exactly one signer); a signer ≠
  message address is `Mismatch { address }`.
- Addresses: base58 32–44 chars decoding to 32 bytes, canonical on-curve
  prime-order-subgroup Ed25519 point — identity and small-order are rejected
  (`InvalidField { address }`).
- Signatures: 64 B, `S < L`, canonical + torsion-free + non-identity `R`;
  noble `ed25519.verify(sig, msg, key, { zip215: false })` on a
  `VerifyingKey::verify_strict`-equivalent rule.
