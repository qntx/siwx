# siwx

A Rust implementation of [Sign-In with X](https://chainagnostic.org/CAIPs/caip-122) (CAIP-122): message construction, parsing, binding checks and signature verification for EVM (`evm` feature, EIP-4361, smart accounts via `rpc`) and Solana (`svm` feature, SIWS). Behaviorally identical to [`@qntx/siwx`](https://www.npmjs.com/package/@qntx/siwx).

See the [documentation](https://github.com/qntx/siwx/tree/main/docs).
