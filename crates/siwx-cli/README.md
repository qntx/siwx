# siwx-cli

Command-line tool for [Sign-In with X](https://chainagnostic.org/CAIPs/caip-122) (binary name `siwx`): build, parse and verify EVM and Solana sign-in messages with JSON output. Wraps the `siwx` crate.

See the [documentation](https://github.com/qntx/siwx/tree/main/docs/rust/cli.mdx).
